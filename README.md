2. ### Install dependencies
	Make sure Python is installed in your system. Follow [this link](https://phoenixnap.com/kb/check-python-version) to check if your system has Python. Below are the list of packages you will need to install for DRE. 
	1. [Pytorch](https://pytorch.org/) 
	2. [NumPy](https://numpy.org/)
	3. [Matplotlib](https://matplotlib.org/)
	
	You can use [pip](https://pypi.org/project/pip/) or any other package manager to install these packages. You can use below command:
	`pip install pytorch numpy matplotlib`
	
3. ### Run the script 
	Open a terminal window (CMD in Windows machines) and type `PYTHONPATH="/path/to" python main.py` to run the script.
